# MGR Informatique

An open-source starter website for MGR Informatique, built with plain HTML, CSS and JavaScript.

## Features
- Responsive layout for desktop and mobile
- Arabic (RTL) and French (LTR) language switch
- Services, about and contact sections
- No build tools or dependencies required

## Run locally
Open `index.html` in a modern web browser.

## Customize before publishing
1. Replace the example email address in `index.html` with your real contact email.
2. Update service descriptions to match the services actually offered.
3. Add official social links and real portfolio projects when available.
4. Review all content and test both language modes on mobile and desktop.

## Contributing
Issues and pull requests are welcome. Please describe proposed changes clearly and test them in a browser.
